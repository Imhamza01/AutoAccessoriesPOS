## BUG 1: Receipt prints `Change = -50` instead of showing Discount correctly

### Root Cause (Deep Analysis)

`applyDiscountToCart()` works by modifying `item.total` proportionally:
```js
item.total = item.price * item.quantity * discountRatio;   // ← discounted total
```

The `updateCartSummary()` uses `item.total` correctly (discounted).
`completePayment()` also uses `item.total` correctly → sends correct `total_amount` to API.

**BUT** `prepareReceiptData()` recalculates subtotal as:
```js
const subtotal = this.cart.reduce((sum, item) => sum + (item.price * item.quantity), 0);
// ↑ This is BEFORE discount — ignores item.total!
```

Then:
```js
const discount = this.currentDiscount || 0;  // Often 0 — not stored properly
const afterDiscount = subtotal - discount;
const grandTotal = afterDiscount + taxAmount;
```

Meanwhile `completePayment()` stores:
```js
this.lastPaymentDetails = {
    amount_tendered: amountTendered,  // e.g. 950 (customer paid)
    change_amount: amountTendered - total,  // total = discounted+tax = 900
    ...
};
```

Then `prepareReceiptData()` computes:
```js
const amountPaid = this.lastPaymentDetails?.amount_tendered || grandTotal;  // 950
const change = amountPaid - grandTotal;  // 950 - 1000 (undiscounted!) = -50
```

**This is the bug**: receipt `grandTotal` uses undiscounted subtotal, but `amountPaid` uses
the actual amount the customer paid (after discount). The difference prints as a negative Change.

### EXACT FIX — `src/frontend/screens/pos/script.js`

#### Step 1: Store `currentDiscount` when discount is applied

In `applyDiscountToCart()`, find where the loop modifies items:
```js
        this.cart.forEach(item => {
            if (item.original_total === undefined) {
                item.original_total = item.price * item.quantity;
            }
            item.discount = item.price * item.quantity * (1 - discountRatio);
            item.total = item.price * item.quantity * discountRatio;
        });

        this.updateCartDisplay();
        this.app.showNotification('Discount of ' + this.app.formatCurrency(discountAmount) + ' applied', 'success');
        this.closeDiscountModal();
```

Add `this.currentDiscount = discountAmount;` before `this.updateCartDisplay()`:
```js
        this.cart.forEach(item => {
            if (item.original_total === undefined) {
                item.original_total = item.price * item.quantity;
            }
            item.discount = item.price * item.quantity * (1 - discountRatio);
            item.total = item.price * item.quantity * discountRatio;
        });

        this.currentDiscount = discountAmount;   // ← ADD THIS LINE

        this.updateCartDisplay();
        this.app.showNotification('Discount of ' + this.app.formatCurrency(discountAmount) + ' applied', 'success');
        this.closeDiscountModal();
```

#### Step 3: Fix `prepareReceiptData()` — use actual discounted subtotal, not raw

Find inside `prepareReceiptData()` (or `printReceipt()` — the one called after `completePayment`):
```js
        // Calculate totals
        const subtotal = this.cart.reduce((sum, item) => sum + (item.price * item.quantity), 0);
        const discount = this.currentDiscount || 0;
        const taxRate = ...
        const afterDiscount = subtotal - discount;
        const taxAmount = afterDiscount * taxRate;
        const grandTotal = afterDiscount + taxAmount;
        const amountPaid = this.lastPaymentDetails?.amount_tendered || grandTotal;
        const change = amountPaid - grandTotal;
```

Replace with:
```js
        // Calculate totals — use item.total (already discounted) not raw price*qty
        const rawSubtotal = this.cart.reduce((sum, item) => sum + (item.price * item.quantity), 0);
        const discountedSubtotal = this.cart.reduce((sum, item) => sum + item.total, 0);
        const discount = this.currentDiscount || (rawSubtotal - discountedSubtotal);

        const taxRate = (settings.gstRate !== undefined && settings.gstRate !== null)
            ? settings.gstRate : 0.17;
        const taxAmount = discountedSubtotal * taxRate;
        const grandTotal = discountedSubtotal + taxAmount;
        const amountPaid = this.lastPaymentDetails?.amount_tendered || grandTotal;
        const change = Math.max(0, amountPaid - grandTotal);   // Never negative
```

Also update the receipt data object to use `rawSubtotal` for the "subtotal before discount" line:
```js

            discount: discount,           // Show discount amount
            taxRate: taxRate,
            taxAmount: taxAmount,
            grandTotal: grandTotal,       // = discountedSubtotal + tax
            amountPaid: amountPaid,
            change: change,
```

#### Add `addAllCustomItems()` method:

```js
addAllCustomItems() {
    const rows = document.querySelectorAll('#custom-items-list .custom-item-row');
    if (rows.length === 0) {
        this.app.showNotification('No items to add', 'error');
        return;
    }

    let addedCount = 0;
    let errors = [];

    rows.forEach((row, index) => {
        const nameInput = row.querySelector('.custom-row-name');
        const qtyInput  = row.querySelector('.custom-row-qty');
        const priceInput = row.querySelector('.custom-row-price');

        const name  = (nameInput?.value || '').trim();
        const qty   = parseFloat(qtyInput?.value) || 0;
        const price = parseFloat(priceInput?.value) || 0;

        // Skip completely empty rows silently
        if (!name && !price) return;

        // Validate
        if (!name) {
            errors.push(`Row ${index + 1}: Description is required`);
            nameInput?.classList.add('error-border');
            return;
        }
        if (qty <= 0) {
            errors.push(`"${name}": Quantity must be > 0`);
            qtyInput?.classList.add('error-border');
            return;
        }
        if (price < 0) {
            errors.push(`"${name}": Price cannot be negative`);
            priceInput?.classList.add('error-border');
            return;
        }

        // Add to cart
        const cartId = 'custom-' + Date.now() + '-' + addedCount;
        this.cart.push({
            product: { id: null, _cartId: cartId, name: name, is_custom: true },
            quantity: qty,
            price: price,
            discount: 0,
            original_total: price * qty,
            total: price * qty
        });
        addedCount++;
    });

    if (errors.length > 0) {
        this.app.showNotification(errors.join('\n'), 'error');
        return; // Don't close modal so user can fix errors
    }

    if (addedCount === 0) {
        this.app.showNotification('Please fill in at least one item', 'error');
        return;
    }

    // Close modal and update cart
    document.getElementById('custom-item-modal-overlay').remove();
    this.updateCartDisplay();
    this.app.showNotification(
        `Added ${addedCount} custom item${addedCount > 1 ? 's' : ''} to cart`,
        'success'
    );
}
```

## BUG 4: Dashboard profit uses hardcoded 30% margin — wrong for every shop

### Root Cause
```js
// Profit (30% assumption)
this.data.todayProfit = todaySales * 0.30;
```
The real profit is stored in `sale_items.line_profit`. Use it.

### EXACT FIX — `src/frontend/screens/dashboard/script.js`

Find:
```js
            // Profit (30% assumption)
            this.data.todayProfit = todaySales * 0.30;
            this.updateStatCard('todayProfit', this.app.formatCurrency(this.data.todayProfit));
```

Replace with:
```js
            // Actual profit from today's sales
            let actualProfit = 0;
            try {
                const today = `${now.getFullYear()}-${String(now.getMonth()+1).padStart(2,'0')}-${String(now.getDate()).padStart(2,'0')}`;
                const profitResp = await this.app.api.get(
                    `/reports/profit-loss?start_date=${today}&end_date=${today}`
                );
                if (profitResp && profitResp.success) {
                    actualProfit = profitResp.total_profit || profitResp.net_profit || 0;
                }
            } catch (e) {
                // Fallback estimate if profit endpoint unavailable
                actualProfit = todaySales * 0.20;
                console.warn('[Dashboard] Profit API unavailable, using 20% estimate');
            }
            this.data.todayProfit = actualProfit;
            this.updateStatCard('todayProfit', this.app.formatCurrency(this.data.todayProfit));
```

## BUG 6: `loadRecentSales` uses trailing slash `/sales/?limit=10` — routing issue

### Root Cause
`src/frontend/screens/dashboard/script.js` calls `/sales/?limit=10` with a trailing
slash before `?`. FastAPI's `redirect_slashes=True` causes a 307 redirect from `/sales/`
to `/sales`, which may drop query parameters.

### EXACT FIX — `src/frontend/screens/dashboard/script.js`

Find:
```js
const response = await this.app.api.get('/sales/?limit=10');
```
Replace with:
```js
const response = await this.app.api.get('/sales?limit=10&skip=0');
```

Find any other `/sales/?` patterns and remove the trailing slash:
```js
// Before:
this.app.api.get(`/sales/?start_date=...`)
// After:
this.app.api.get(`/sales?start_date=...`)
```
